# World Navigation & Checkpoint Guidelines
- **Checkpoint System:** Place activation shrines throughout the open world that save player progress and respawn points upon death.
- **Teleporter Network:** Create fast-travel portals linking discovered map zones to reduce tedious backtracking in the open world.
- **Consumable Mechanics:** Implement quick-use healing potions and runes that can be bound to hotkeys or touch UI buttons.
