# 2D Sprite Generator Guidelines
- Use Python's `PIL` (Pillow) library to programmatically generate 2D pixel art, tiles, or UI button icons.
- Save generated assets directly into a `/assets/` subfolder in the project directory.
- Keep image dimensions small (e.g., 32x32 or 64x64) for optimal mobile performance and retro aesthetics.
