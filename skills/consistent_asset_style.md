# Consistent 2D Asset Generation Guidelines
- **Color Palette Locking:** Always adhere to a unified color palette across all related game assets (e.g., specific HEX/RGB ranges for ground tiles, player sprites, and UI elements) to ensure a cohesive visual theme.
- **Dimension & Scale Uniformity:** Maintain strict grid proportions (e.g., strictly 32x32 pixels for tiles and items, or consistent scaling ratios for characters) so all assets fit together seamlessly.
- **Shading & Border Rules:** Apply uniform shading conventions (such as a consistent light source from the top-left, 1-pixel dark outlines, and standard highlight placement) to prevent clashing art styles between generated files.
