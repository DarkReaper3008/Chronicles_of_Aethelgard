# Character Progression & Skill Tree Guidelines
- Structure the skill tree as a hierarchical JSON tree where nodes unlock sequentially based on available skill points or collected runes.
- Implement randomized element affinities (e.g., Pyromancy, Cryomancy, Storm) assigned to the character upon game start or rebirth.
- Track weapon and armor ranks (e.g., Common -> Rare -> Epic -> Legendary) that scale base stats and unlock visual upgrades.
