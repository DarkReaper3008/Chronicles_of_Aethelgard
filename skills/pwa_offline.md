# Progressive Web App (PWA) Guidelines
- Always include a lightweight `manifest.json` and a service worker to support offline caching.
- Design mobile-first layouts with responsive viewports (`meta name="viewport" content="width=device-width, initial-scale=1.0"`).
- Prioritize local-first data persistence using `localStorage` or IndexedDB so apps function without internet connectivity.
