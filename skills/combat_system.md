# RPG Combat & Elemental Mechanics Guidelines
- Implement a clear entity component or class system for enemies, NPCs, and the player.
- Structure elemental spells with distinct attributes (element type, cooldown, mana cost, damage multiplier, and status effects).
- Use clean bounding-box or radius checks to determine when a spell projectile successfully hits an enemy entity.
